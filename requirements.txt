# ============================================================================
# TROUBLESHOOTING
# ============================================================================

# Problem: torch installation fails
# Solution: Install specific version for your system
#   - CUDA 11.8: pip install torch --index-url https://download.pytorch.org/whl/cu118
#   - CUDA 12.1: pip install torch --index-url https://download.pytorch.org/whl/cu121
#   - CPU only:  pip install torch --index-url https://download.pytorch.org/whl/cpu
#
# Problem: chromadb installation fails
# Solution: Update pip first
#   - python -m pip install --upgrade pip
#   - pip install chromadb
#
# Problem: sentence-transformers slow to install
# Solution: Install pre-built wheel
#   - pip install sentence-transformers --prefer-binary
#
# Problem: Out of memory errors
# Solution: Use smaller models or increase swap space
#   - Use T5-base instead of T5-large
#   - Use ollama-llama-3.2 (3B) instead of larger models
