Exception Modeler: ML-driven runtime exception modeling, root cause analysis, and failure pattern detection.

---

## 🌟 Key Features

- 🐛 **Stack Trace Clustering**: Groups similar runtime exceptions using NLP and ML embeddings.
- 📊 **Root Cause Analyzer**: Pinpoints failing code modules and upstream trigger conditions.
- 💡 **Fix Recommendation Engine**: Generates automated patch suggestions for common exception types.
- 📈 **Interactive Streamlit Dashboard**: Real-time visualization of error frequency and distribution.
